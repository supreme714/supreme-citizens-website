# January 6 Phase 7 — You Decide & Citizen Analysis

Phase 7 adds a structured citizen-analysis layer to the January 6 Memory, Record & Republic project.

## Components

- `j6-you-decide.html` — the existing public-facing civic inquiry framework and fourteen major questions.
- `j6-citizen-analysis.html` — a visible record interface assigning stable `J6-A` identifiers to the fourteen questions and linking them to the existing evidence ledger where applicable.
- `data/j6-citizen-analysis.json` — structured data for the analysis questions, assessment scale, evidence references, analytical disciplines and privacy standard.

## Editorial standard

The analysis layer does not assign political conclusions. It requires readers to distinguish allegations, official records, congressional findings, judicial holdings, case-specific outcomes and later developments. Certainty should match the strength of the record.

## Privacy standard

Any future interactive citizen assessment should be private by default and should not be used to construct a political profile.
