# Phase 10B — Sitewide Unified Navigation Deployment

This integration stage follows the approved Phase 10 navigation prototype.

The accompanying workflow is designed to apply the approved unified navigation architecture to the shared `assets/site.js` layer so pages that use the standard Supreme Citizens navigation receive the same structure without rewriting page content.

Approved architecture:

- Home
- Charter
- 12 Principles
- Supreme Citizen
- Citizens Branch
- Community of Consensus
- Participate
- Elections & Government
  - Election Day
  - Voting
  - Election Participation Pathway
  - Congressional Certification
  - January 6
  - Connect With Congress
- Resources
  - Citizenship & Due Process
  - Continuous Civic Participation
  - Founding Documents
  - About
  - Info & Contact

The implementation includes desktop dropdowns, keyboard/focus behavior, responsive mobile expansion, and preserves existing page content. The deployment remains preview-first before any navigation replacement is accepted for the public site.
